# overload Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `overload`, a macOS terminal TUI that shows processes sorted by CPU and kills any one with a single keypress (SIGTERM, escalating to SIGKILL), while refusing to kill system-critical processes.

**Architecture:** Four focused modules — `collector` (snapshot processes via `sysinfo`), `classifier` (pure function tagging each process Killable/Protected), `killer` (send SIGTERM, escalate to SIGKILL after 2s), `ui` (Ratatui table + a pure key reducer). `main` wires them into a 1.5s refresh event loop.

**Tech Stack:** Rust (edition 2021), Ratatui + crossterm (TUI/input), sysinfo (process data), nix (signals + liveness check).

## Global Constraints

- Platform: macOS only for v1.
- Rust edition: 2021.
- Distribution: single binary via `cargo build --release`.
- Kill is instant on keypress — NO confirmation prompt.
- Protected names (never killable): `WindowServer`, `kernel_task`, `launchd`, `loginwindow`, `WindowManager`, `coreaudiod`, `mds`, `mds_stores`. Also any PID < 100.
- Process list sorted by CPU descending.
- Refresh interval: 1500 ms.

```rust
/// Returns true if the process exists (including as a zombie).
pub fn is_alive(pid: u32) -> bool {
    // Signal 0 performs error checking without sending a signal.
    match nix_kill(Pid::from_raw(pid as i32), None) {
        Ok(()) => true,
        Err(nix::errno::Errno::EPERM) => true, // exists, but not ours
        Err(_) => false,
    }
}

/// Send SIGTERM; if still alive after 2s, send SIGKILL. Refuses protected pids.
pub fn kill(pid: u32, name: &str) -> Result<(), KillError> {
    if classify(name, pid) == Protection::Protected {
        return Err(KillError::Protected);
    }

    let target = Pid::from_raw(pid as i32);
    match nix_kill(target, Signal::SIGTERM) {
        Ok(()) => {}
        Err(nix::errno::Errno::ESRCH) => return Err(KillError::NotFound),
        Err(nix::errno::Errno::EPERM) => return Err(KillError::PermissionDenied),
        Err(_) => return Err(KillError::Other),
    }

    // Escalate in the background so the UI never blocks.
    std::thread::spawn(move || {
        std::thread::sleep(Duration::from_secs(2));
        if is_alive(pid) {
            let _ = nix_kill(target, Signal::SIGKILL);
        }
    });

    Ok(())
}
```

```rust
impl Collector {
    pub fn new() -> Self {
        let sys = System::new_with_specifics(
            RefreshKind::nothing().with_processes(ProcessRefreshKind::everything()),
        );
        let total_mem = sys.total_memory().max(1);
        Collector { sys, total_mem }
    }

    pub fn snapshot(&mut self) -> Vec<ProcRow> {
        self.sys
            .refresh_processes(sysinfo::ProcessesToUpdate::All, true);

        let mut rows: Vec<ProcRow> = self
            .sys
            .processes()
            .iter()
            .map(|(pid, p)| ProcRow {
                pid: pid.as_u32(),
                name: p.name().to_string_lossy().to_string(),
                cpu_pct: p.cpu_usage(),
                ram_pct: (p.memory() as f64 / self.total_mem as f64 * 100.0) as f32,
            })
            .collect();

        rows.sort_by(|a, b| {
            b.cpu_pct
                .partial_cmp(&a.cpu_pct)
                .unwrap_or(std::cmp::Ordering::Equal)
        });
        rows
    }
}
```

```rust
impl App {
    pub fn new() -> Self {
        App { rows: Vec::new(), selected: 0, status: None }
    }

    pub fn set_rows(&mut self, rows: Vec<ProcRow>) {
        self.rows = rows;
        let max = self.rows.len().saturating_sub(1);
        if self.selected > max {
            self.selected = max;
        }
    }

    pub fn handle_key(&mut self, code: KeyCode) -> Action {
        match code {
            KeyCode::Char('q') | KeyCode::Esc => Action::Quit,
            KeyCode::Down => {
                if self.selected + 1 < self.rows.len() {
                    self.selected += 1;
                }
                Action::None
            }
            KeyCode::Up => {
                self.selected = self.selected.saturating_sub(1);
                Action::None
            }
            KeyCode::Char('k') => {
                let Some(r) = self.rows.get(self.selected) else {
                    return Action::None;
                };
                match classify(&r.name, r.pid) {
                    Protection::Protected => {
                        self.status = Some(format!("{} is protected — not killed", r.name));
                        Action::None
                    }
                    Protection::Killable => Action::Kill(r.pid),
                }
            }
            _ => Action::None,
        }
    }
}
```

```rust
use crate::classifier::{classify, Protection};
use crate::collector::Collector;
use crate::ui::{Action, App};
use crossterm::event::{self, Event};
use crossterm::terminal::{disable_raw_mode, enable_raw_mode, EnterAlternateScreen, LeaveAlternateScreen};
use crossterm::execute;
use ratatui::prelude::*;
use ratatui::widgets::{Block, Borders, Row, Table};
use std::io::{self, stdout};
use std::time::{Duration, Instant};

const REFRESH: Duration = Duration::from_millis(1500);

fn render(frame: &mut Frame, app: &App) {
    let area = frame.area();
    let header = Row::new(vec!["PID", "CPU%", "RAM%", "NAME"]).bold();

    let rows: Vec<Row> = app.rows.iter().enumerate().map(|(i, r)| {
        let protected = classify(&r.name, r.pid) == Protection::Protected;
        let label = if protected { format!("{}  · protected", r.name) } else { r.name.clone() };
        let mut style = if protected { Style::default().fg(Color::DarkGray) } else { Style::default() };
        if i == app.selected {
            style = style.bg(Color::Blue).add_modifier(Modifier::BOLD);
        }
        Row::new(vec![
            r.pid.to_string(),
            format!("{:.0}", r.cpu_pct),
            format!("{:.1}", r.ram_pct),
            label,
        ]).style(style)
    }).collect();

    let title = match &app.status {
        Some(s) => format!(" overload — {s} "),
        None => format!(" overload — {} procs   [↑↓] move  [k] kill  [q] quit ", app.rows.len()),
    };

    let widths = [Constraint::Length(7), Constraint::Length(6), Constraint::Length(6), Constraint::Min(10)];
    let table = Table::new(rows, widths)
        .header(header)
        .block(Block::default().borders(Borders::ALL).title(title));

    frame.render_widget(table, area);
}

fn main() -> io::Result<()> {
    enable_raw_mode()?;
    let mut out = stdout();
    execute!(out, EnterAlternateScreen)?;
    let backend = CrosstermBackend::new(out);
    let mut terminal = Terminal::new(backend)?;

    let mut collector = Collector::new();
    let mut app = App::new();
    app.set_rows(collector.snapshot()); // prime
    let mut last = Instant::now();

    let result = run(&mut terminal, &mut collector, &mut app, &mut last);

    disable_raw_mode()?;
    execute!(terminal.backend_mut(), LeaveAlternateScreen)?;
    terminal.show_cursor()?;
    result
}

fn run<B: Backend>(
    terminal: &mut Terminal<B>,
    collector: &mut Collector,
    app: &mut App,
    last: &mut Instant,
) -> io::Result<()> {
    loop {
        terminal.draw(|f| render(f, app))?;

        if event::poll(Duration::from_millis(200))? {
            if let Event::Key(key) = event::read()? {
                if key.kind == event::KeyEventKind::Press {
                    match app.handle_key(key.code) {
                        Action::Quit => return Ok(()),
                        Action::Kill(pid) => {
                            let name = app.rows.iter().find(|r| r.pid == pid)
                                .map(|r| r.name.clone()).unwrap_or_default();
                            match killer::kill(pid, &name) {
                                Ok(()) => app.status = Some(format!("killing {name} ({pid})…")),
                                Err(e) => app.status = Some(format!("{name}: {e:?}")),
                            }
                        }
                        Action::None => {}
                    }
                }
            }
        }

        if last.elapsed() >= REFRESH {
            let selected_pid = app.rows.get(app.selected).map(|r| r.pid);
            app.set_rows(collector.snapshot());
            // keep cursor on the same pid if it still exists
            if let Some(pid) = selected_pid {
                if let Some(idx) = app.rows.iter().position(|r| r.pid == pid) {
                    app.selected = idx;
                }
            }
            *last = Instant::now();
        }
    }
}
```

## Notes for the implementer

- Dependency versions (`ratatui` 0.29, `crossterm` 0.28, `sysinfo` 0.33, `nix` 0.29) are starting points. If `cargo build` reports API mismatches, run `cargo doc -p <crate> --open` and adapt the call sites — but the public type shapes and behaviors defined in each task's **Interfaces** block must not change.
- The escalation thread in `killer::kill` is fire-and-forget by design; the UI must never block waiting on a kill.
- CPU% from `sysinfo` is meaningful only after two refreshes; the loop primes once at startup, so the first frame may show 0% for some rows — this self-corrects on the first 1.5s tick.
